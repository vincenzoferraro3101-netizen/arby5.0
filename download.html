Compatibile con Windows 10 / 11 — Richiede MetaTrader 5

SCARICA ORA
ARBEXA.zip  ·  Windows 64-bit
Procedura di Installazione
1

Scarica il file

Clicca sul tasto "SCARICA ORA" qui sopra. Il file arbexa.exe verrà salvato nella cartella Download del tuo PC.

2

Crea una cartella dedicata

Prima di avviare il programma, crea una cartella sul Desktop chiamata ARBEXA e sposta arbexa.exe al suo interno. ArbeXa salverà tutti i dati di configurazione in questa cartella — non spostarla in seguito.

3

Avvia il programma

Fai doppio clic su arbexa.exe dalla cartella ARBEXA. Se Windows mostra un avviso di sicurezza, vai al punto successivo.

4

Inserisci il codice di attivazione

Al primo avvio vedrai il tuo ID Cliente. Comunicalo al tuo operatore per ricevere il codice di attivazione, poi inseriscilo e clicca ATTIVA LICENZA.

5

Inserisci la password e accedi

Dopo l'attivazione inserisci la password fornita dal tuo operatore e clicca ENTRA per accedere alla dashboard.

⚠ Avviso Windows Defender / SmartScreen

Windows potrebbe bloccare l'esecuzione di ArbeXa mostrando un avviso di sicurezza. Questo è normale per software non distribuiti tramite i canali ufficiali Microsoft. Il programma è sicuro — ecco come procedere:

  • Se appare "Windows ha protetto il PC" → clicca "Ulteriori informazioni"
  • Poi clicca "Esegui comunque"
  • ArbeXa si avvierà normalmente
Risoluzione Problemi Comuni

⚡ Windows Defender rimuove il file automaticamente

In alcuni casi Windows Defender potrebbe rimuovere automaticamente arbexa.exe dopo il download.

Soluzione: Aggiungi la cartella ARBEXA alle esclusioni di Windows Defender.

1. Apri Sicurezza di Windows dal menu Start
2. Vai su Protezione da virus e minacce
3. Clicca su Gestisci impostazioni
4. Scorri fino a Esclusioni e clicca Aggiungi o rimuovi esclusioni
5. Clicca + Aggiungi esclusione → Cartella
6. Seleziona la cartella ARBEXA sul Desktop
7. Riscarica arbexa.exe nella cartella ARBEXA

⚡ "Impossibile avviare l'applicazione" o errore DLL

Potrebbe mancare un componente di sistema necessario.

Soluzione: Installa il pacchetto redistribuibile Microsoft Visual C++:

Scarica e installa Microsoft Visual C++ Redistributable (x64) dal sito ufficiale Microsoft, poi riavvia il PC e riprova.

⚡ Il programma si apre ma non si connette al server

ArbeXa non riesce a comunicare con i server di sniperpro.online.

Soluzione:
1. Verifica la connessione Internet
2. Controlla che il firewall di Windows non stia bloccando arbexa.exe
3. Se usi un antivirus di terze parti, aggiungi arbexa.exe alle eccezioni
4. Riavvia il programma

⚡ Licenza non valida dopo reinstallazione

Se reinstalli Windows o cambi PC la licenza potrebbe non essere più valida perché è legata al dispositivo.

Soluzione: Contatta il tuo operatore su Telegram per richiedere il trasferimento della licenza al nuovo dispositivo. Fornisci il nuovo ID Cliente che apparirà al primo avvio.

⚡ ArbeXa non riesce ad aprire ordini su MetaTrader 5

Il percorso al file terminal64.exe non è configurato correttamente.

Soluzione:
1. Assicurati che MetaTrader 5 sia aperto e connesso al broker
2. Nella scheda di ArbeXa, clicca ... accanto al campo PROP o HEDGE
3. Naviga fino alla cartella di installazione di MT5 (es. C:\Program Files\MetaTrader 5\)
4. Seleziona il file terminal64.exe e clicca OK
5. Ripeti per entrambi i conti PROP e HEDGE
